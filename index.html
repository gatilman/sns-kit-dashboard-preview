🧙 SNS 자동화 키트 설치 마법사

아래 순서(1→6)대로 버튼만 누르시면 됩니다. 원래 설명서에서 제일 번거로운 두 가지 — "내 저장소 만들기"와 "비밀키 20여 개 하나씩 입력하기" — 를 이 페이지가 대신 처리해드려요. (인스타그램·유튜브 같은 각 서비스에 계정을 만드는 것 자체는 본인 명의라서 대신 해드릴 수 없어요 — 그 부분만 각 서비스 화면에서 직접 하시면 됩니다. 네이버 블로그는 자동으로 못 올려드려서, 완성된 글을 드리면 복사해서 붙여넣기만 하시면 됩니다.)

🔒 여기 입력하시는 건 어디에도 저장되지 않아요. 토큰·키를 입력하시면 이 화면에서 곧바로 GitHub로(그리고 6단계 "설정값 확인"을 쓰실 때만 구글로도) 전달될 뿐, 판매자를 포함해 그 누구의 서버도 거치지 않습니다. 페이지를 새로고침하면 방금 입력하신 값은 전부 사라져요 — 그러니 중간에 실수로 새로고침하지 않게만 주의해주세요.
⚠️ 2단계(내 보관함 만들기)가 안 되시나요? 결제가 확인되면 판매자가 GitHub에서 회원님을 초대해드려요 — 그 초대를 받기 전까지는 2단계가 원래 안 됩니다. 초대가 늦어진다 싶으면 크몽 메시지로 문의해주세요.

1 출입증 만들기 (GitHub 토큰)

이 페이지가 회원님 GitHub 계정에 대신 들어가서 "보관함 만들기·비밀키 넣기"를 하려면, 짧은 기간만 쓸 수 있는 임시 출입증이 하나 필요해요. 아래 4단계만 그대로 따라 하시면 1분이면 끝나요.
  1. 1아래 버튼을 누르세요 → 새 탭이 열리고 필요한 권한이 이미 체크돼 있어요. 그대로 두시면 됩니다.
    🔗 출입증 만들러 가기 (새 탭 열림)
  2. 2그 페이지 중간의 Expiration(유효기간)을 7 days로 바꿔주세요 — "이 출입증을 며칠 동안 쓸지" 정하는 항목이에요.
  3. 3페이지 맨 아래 초록색 Generate token 버튼을 눌러주세요.
  4. 4ghp_로 시작하는 긴 글자가 딱 한 번만 화면에 나타나요 — 그 순간 바로 복사해서 이 페이지로 돌아와 아래 칸에 붙여넣어주세요(놓치면 처음부터 다시 만들어야 해요).
💡 이 출입증은 설치가 끝나면 바로 없애버리셔도 안전해요 — GitHub 설정에서 "삭제(Revoke)"만 누르면 끝입니다.

2 내 전용 보관함 만들기

이 자동화 프로그램을 통째로 복사해서, 회원님 계정 밑에 회원님만의 것으로 하나 새로 만드는 단계예요. 이름은 자유롭게 지으셔도 됩니다.

3 비밀번호(Secrets) 넣기

여기 넣는 값들은 자동화가 여러분 대신 인스타그램에 글을 올리거나 AI에게 글을 부탁할 때 "제가 진짜 이 계정 주인이에요"라고 증명하는 비밀번호 같은 거예요. 각 값은 SETUP.md에서 발급받으신 그대로 붙여넣으시면 됩니다. 안 쓰실 기능은 그냥 비워두세요 — 그 기능만 자동으로 꺼집니다.

🔑 먼저 이것부터: 오래 쓰는 토큰으로 바꾸기

메타에서 처음 받는 토큰은 며칠 지나면 만료돼요. 3단계에서 받은 앱 시크릿과 방금 받은 토큰을 아래에 넣고 버튼을 누르면, 오래 써도 되는 토큰으로 바꿔주는 새 탭이 열립니다(그 페이지에 나오는 access_token 값을 복사해서 아래 칸에 붙여넣으세요). 쓰레드도 쓰실 거면 쓰레드 토큰으로 바꿔 넣고 버튼만 다시 누르면 됩니다.

2·3단계가 끝났으면, 원하는 자동화 작업을 아래 버튼으로 직접 눌러서 테스트해볼 수 있어요. 구글시트 "설정" 탭이 비어있으면 "일일 자동화"는 실패하는 게 정상이에요 — 시트를 채우신 다음 다시 눌러보시면 됩니다.

6 지금 저장된 설정값 확인

구글시트 "설정" 탭(브랜드명·타겟고객 같은 정보)에 지금 뭐가 채워져 있는지 보여드려요. 위 3단계에서 GOOGLE_CLIENT_EMAIL / GOOGLE_PRIVATE_KEY / GOOGLE_SHEETS_SPREADSHEET_ID를 이미 입력하셨다면 다시 입력할 필요 없이 그대로 씁니다. 단, API 키 같은 진짜 비밀값은 여기서도 안 보여드려요 — GitHub 구조상 한 번 등록한 값은 그 누구도(판매자도) 다시 읽어올 수 없게 돼 있거든요. "등록이 됐는지 안 됐는지"는 위 3단계 업로드 결과로 확인하시면 됩니다.
