🧙 SNS 자동화 키트 설치 마법사

SETUP.md의 "저장소 만들기 + Secrets 20여 개 입력" 부분을 대신 해드립니다. 나머지(구글/메타 계정 만들기·동의)는 각 서비스 화면에서 직접 진행하셔야 합니다. (네이버 블로그는 API가 막혀있어 자동 연동이 없습니다 — 초안을 만들어드리면 직접 복사-붙여넣기만 하시면 됩니다.)

🔒 이 페이지는 순수 정적 HTML입니다. 아래 입력하는 토큰/키는 이 브라우저에서 GitHub API(api.github.com)로, "설정값 확인" 기능을 쓰실 경우엔 구글 인증 서버(oauth2.googleapis.com, sheets.googleapis.com)로 직접 전송될 뿐, 어디에도 저장되거나 판매자 서버를 거치지 않습니다. 페이지를 새로고침하면 입력값은 전부 사라집니다.
⚠️ 템플릿 저장소는 비공개입니다. 결제 후 판매자가 GitHub 계정을 협업자로 초대해드려야 2단계(저장소 만들기)가 됩니다. 아직 초대를 못 받으셨으면 판매자에게 문의해주세요.

1 GitHub 개인 액세스 토큰

아래 4단계만 순서대로 하시면 됩니다.
  1. 1아래 🔗 토큰 만들기 버튼을 누르세요 — 새 탭이 열리고 이름·권한(repo, workflow)이 이미 체크되어 있습니다.
    🔗 토큰 만들기 버튼 (새 탭 열림)
  2. 2그 페이지에서 Expiration(만료 기간)을 7 days로 선택하세요.
  3. 3페이지 맨 아래 초록색 Generate token 버튼을 클릭하세요.
  4. 4ghp_로 시작하는 값이 딱 한 번 화면에 뜹니다 — 복사해서 이 페이지로 돌아와 아래 칸에 붙여넣으세요.
💡 설치가 끝나면 이 토큰은 GitHub 설정에서 바로 삭제(Revoke)해도 됩니다.

2 내 저장소 만들기

이 템플릿(gatilman/sosang-sns-kit)을 내 계정으로 복제합니다.

3 Secrets 값 입력

SETUP.md 각 단계에서 발급받은 값을 여기 붙여넣으세요. 선택 항목은 안 쓸 채널이면 비워두면 됩니다(그 채널만 자동으로 꺼집니다).
필수 — AI 제공사 선택 + 구글 시트·드라이브
⚠️ 여기서 고른 제공사와 구글시트 "설정" 탭의 "AI 제공사 선택" 값이 반드시 같아야 합니다. 아직 Claude만 실전 검증됐고, Gemini/GPT는 대표 확인 전까지는 시험 단계입니다.
필수 — 인스타그램/쓰레드

🔑 먼저: 장기 토큰 만들기

3단계 앱 시크릿과 방금 받은 토큰을 넣고 버튼을 누르면 새 탭에 등록할 값이 나옵니다(access_token 값을 아래 칸에 붙여넣으세요). 쓰레드도 쓸 거면 쓰레드 토큰으로 바꿔 넣고 버튼만 다시 누르면 됩니다.

선택 — 유튜브 / 블로그스팟(공용 OAuth)
필수 — Pexels / Cloudinary
필수 — 라이선스
선택 — 텔레그램 알림
선택 — AI 나레이션 음성(Typecast)

4 워크플로우 실행

저장소/Secrets가 다 준비됐으면 필요한 워크플로우를 직접 실행해볼 수 있습니다. 구글시트 "설정" 탭이 비어있으면 일일 자동화는 실패하는 게 정상입니다 — 시트를 채우고 다시 눌러보세요.

5 실행 이력 보기

최근 실행 기록을 읽기 전용으로 확인합니다.

6 설정값 확인

구글시트 "설정" 탭에 지금 채워진 값을 읽기 전용으로 보여줍니다. 위 3단계에서 GOOGLE_CLIENT_EMAIL / GOOGLE_PRIVATE_KEY / GOOGLE_SHEETS_SPREADSHEET_ID를 이미 입력했다면 그대로 재사용합니다(다시 입력할 필요 없음). API 키 같은 비밀값은 여기 안 보입니다 — GitHub Secrets는 한 번 등록하면 값을 다시 읽어올 수 없는 구조라(GitHub 자체 제약), "등록됨/안 됨"만 위 로그로 확인 가능합니다.
